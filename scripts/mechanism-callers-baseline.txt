# su categoria y su razon. Lo lee `scripts/check-mechanism-callers.py` (REQ-013).
#
# ESTO ES UN TRINQUETE, NO UNA LISTA DE EXCEPCIONES. El lint falla si:
#   - aparece una funcion que no esta aca        (deuda nueva sin declarar), Y TAMBIEN
#   - una entrada de aca ya no se reproduce      (la entrada quedo mintiendo)
#
# El segundo corte es el que importa a los seis meses: sin el, el archivo se
# vuelve un cementerio de razones que ya no aplican y nadie lo nota. Mismo
# mecanismo que `scripts/rt-safety-baseline.txt`, `scripts/rt-coverage-baseline.txt`
# y `audio/src/main/cpp/effects/tests/reset-baseline.txt`.
#
# LA RAZON ES OBLIGATORIA. Una entrada sin razon hace fallar el lint, por la
# misma regla que `// RT-SAFE-ALLOW:`: una excepcion tiene que costar escribir
# por que, no ser gratis.
#
# Formato:  <archivo>::<Clase::funcion>::<categoria> | <razon>
# (se parsea desde la derecha: el qname lleva `::` adentro)
#
# LAS CUATRO CATEGORIAS
# ---------------------
#   entrada           definida en `api/` o `jni/`. Es el borde del sistema: no
#                     tiene llamador aguas arriba POR CONSTRUCCION, porque su
#                     consumidor vive fuera del arbol.
#   callback-externo  lo despacha un framework (Oboe, CoreAudio, libusb) por una
#                     interfaz, no nuestro codigo.
#   sonda-de-tests    existe para que un test pueda observar o sincronizar:
#                     contador RT, accesor de estado, hook declarado. NO es
#                     deuda: es la unica forma de verificar lo que el callback
#                     no puede contar.
#   deuda             un mecanismo REAL de produccion sin llamador. Es la clase
#                     que este REQ vino a atacar, y cada una lleva su hallazgo
#                     escrito. NO se declaran para olvidarlas.
#
# `override-virtual` NO es una categoria, y eso es un hallazgo de REQ-013 S2: es
# VACIA POR CONSTRUCCION. Si produccion despachara el virtual, la fusion
# conservadora por nombre simple ya habria suprimido el reporte de todos sus
# overrides. Un override que llega hasta aca es un override que NADIE invoca.
#
