# Engines cuya FUNDAMENTAL se corre al cambiar de sample rate, medido por
# `EnginePitch.TheFundamentalDoesNotShiftBetweenSampleRates`.
#
# El criterio de WD-2.3.2: la misma nota tiene que sonar igual de afinada en un
# device que negocia 44,1 kHz y en uno que negocia 96. El umbral es 5 cents, que
# es donde un oido entrenado empieza a notar la diferencia.
#
# ESTO ES UN TRINQUETE, NO UNA LISTA DE EXCEPCIONES. El test falla si:
#   - un engine que NO esta aca empieza a correrse   (deuda nueva), y TAMBIEN
#   - un engine que SI esta aca deja de correrse     (deuda pagada: borrar linea)
#
# Misma semantica que `effects/tests/reset-baseline.txt` y
# `scripts/rt-safety-baseline.txt`.
#
# Formato:  <ENGINE> | <corrimiento medido> | <causa>
#
# ---------------------------------------------------------------------------
# UNA SOLA CAUSA, Y ESTA MEDIDA. El lazo de Karplus-Strong deberia medir `fs/f`
# muestras y mide `fs/f + D`, con D CONSTANTE — 6,8 / 7,07 / 7,13 muestras para
# 110 / 220 / 440 Hz. Son el retardo de grupo del filtro de un polo del lazo mas
# el del interpolador de la linea de retardo, y nadie los descuenta.
#
# De ahi salen los DOS sintomas, que son el mismo:
#
#   1. LA CUERDA ESTA DESAFINADA BAJA en terminos absolutos, y tanto mas cuanto
#      mas aguda la nota, porque el error relativo es D*f/fs:
#
#          pedido      44,1 kHz     48 kHz      96 kHz
#          110 Hz      -29 cents    -27         -14
#          220 Hz      -61          -56         -28
#          440 Hz      -118         -108        -57
#
#      A 440 Hz sobre 44,1 kHz eso es UN SEMITONO ENTERO. No hace falta ningun
#      instrumento para oirlo.
#
#   2. Y por el mismo D*f/fs, el error BAJA con el sample rate — o sea que la
#      misma nota suena distinto segun el device. Eso es lo que declara este
#      archivo.
#
# COMPENSAR D ARREGLA LOS DOS DE UNA. `EnginePitch.TheKarplusLoopIsLongerThanIt
# AsksFor` mide D directamente y es el test que le sirve a quien lo arregle: no
# dice "esta desafinado", dice cuanto sobra.
#
# OJO: el sintoma 1 —el absoluto— NO esta declarado aca, porque este trinquete
# es sobre invariancia de rate. Vive en el limite de 8 muestras de ese otro test.
# ---------------------------------------------------------------------------

KARPLUS_STRONG | hasta 61 cents entre 44,1 y 96 kHz a 440 Hz | D ~= 7 muestras de sobra en el lazo, sin compensar
