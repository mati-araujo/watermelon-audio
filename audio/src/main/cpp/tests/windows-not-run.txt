# Tests que se registran en Windows y salen SKIPPED con `[windows-not-run]` (REQ-061 AC-061.1).
# Una linea por test: `Suite.Test | razon`. Lo agrega quien pone WMA_WINDOWS_NOT_RUN("razon") en el test
# (tests/support/WindowsNotRun.h); scripts/check-windows-not-run.py exige que listado y macro coincidan,
# y que la corrida en Windows saltee exactamente estos. Un test que PUEDE correr en Windows no va aca.
# Ademas de `Suite.Test | razon`, el listado declara (scripts/check-windows-not-run.py, cada entrada con razon y
# trinquete en las dos direcciones: si sobra o falta, rojo):
#   variante | Suite.Test | razon    el test corre en las dos plataformas pero su CUERPO tiene un #if de plataforma
#   ambiente | <prefijo> | razon     un skip de AMBIENTE en la corrida de Windows: el prefijo exacto de su mensaje
#   cmake | ruta | construccion | razon   UN hallazgo de un CMake de tests (archivo + construccion normalizada, p. ej.
#                                    `if(WIN32) => return()`): excluye, filtra o corta algo bajo una condicion de plataforma
#   fuera | ruta | condicion | razon  un `#if` de plataforma FUERA de los cuerpos de TEST (`if defined(_WIN32)`); sin numeros
#                                    de linea; la misma condicion N veces en el archivo = N entradas
#   deshabilitado | Suite.Test | razon  un TEST con prefijo DISABLED_ (no corre en ninguna plataforma)
#   solo-windows | nombre | razon    un test (Suite.Test) o una fuente (archivo.cpp) que existe SOLO en Windows
#   posix-solo | target | Suite.Test | razon   un test que se compila/registra en POSIX y NO en Windows (diff por nm de windows-cross)
